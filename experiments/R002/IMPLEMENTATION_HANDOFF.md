## 3. Validate equivalence, hardening, and resumption

Check the shared relaxed function before training:

- All Boolean input pairs and a fractional input grid.
- Matched effective truth tables, complete soft rollouts, loss, and state
  Jacobian-vector products at initialization and nontrivial matched functions.
- Gradients within each representation against an independent small check, such
  as finite differences in FP64. Parameter gradients across the 16- and
  four-coordinate representations are expected to differ.

Implement extraction explicitly:

- Native categorical hardening: source argmax over 16 gate logits.
- Common truth hardening: round `q >= 0.5`, then encode gate ID using bit weights
  `[8,4,2,1]` for columns `00,01,10,11`.
- Direct truth-table hardening is the latter rule. Argmax over four truth logits
  is not a Boolean gate decoder.

Check each export against its own hard execution on identical inputs. Preserve
the distinction between native and common hardening in metrics, summaries, and
artifact names. Never compare a categorical native score to an unlabeled direct
score as if the extraction rule were held fixed.

Checkpoint and resume every condition, including parameters, optimizer moments,
RNG, and update index. Include representation, condition, kernel, pairing hashes,
and config identity in metadata, so loaders cannot interpret four-entry logits
as sixteen categorical scores. Verify the next resumed update against the
uninterrupted update within the same condition.
